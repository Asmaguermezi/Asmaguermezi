## 🌷 Featured project · Etudia

**Etudia** is a real-time study platform I built as my final-year project.

- 🎥 Students can join live video study sessions.
- 💬 They can post comments and receive in-app notifications.
- 🛠️ Administrators can manage users, subjects, and sessions.

**Built with** React, Tailwind CSS, Node.js, Express, MongoDB, Socket.IO, WebRTC, and JWT.
